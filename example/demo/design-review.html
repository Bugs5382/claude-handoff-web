Settings screen: design review

Answer each section Yes, No or Changes, then More, Copy results, and paste it back.

Purpose and behaviour

The settings screen lets a signed-in user change their display name, notification e-mails and theme. Every change saves on its own, with a short "Saved" note next to the field.

Layout

+--------------------------------------------+
| Settings                                   |
| [ Profile ]  [ Notifications ]  [ Theme ]  |
|--------------------------------------------|
| Display name   [ Sam Example        ]      |
| E-mail         sam@example.org             |
|                                            |
|                             [ Sign out ]   |
+--------------------------------------------+

Tabs across the top; each tab is one short form.

Errors and empty states

A failed save keeps the typed value, turns the field border red and shows "Couldn't save, retrying". With no notification rules yet, the tab shows one line and an "Add a rule" button.
